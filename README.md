# FocusFlow – Static Study Planner Website

## Task Overview

FocusFlow is a responsive static website designed to help students organize their study tasks and manage their focus time. It provides a simple and attractive interface for planning daily activities and tracking progress.

## Objectives

- Build an interactive static website using HTML, CSS, and JavaScript.
- Create a responsive design for desktop and mobile devices.
- Practice using Git and GitHub for version control.
- Deploy the website using GitHub Pages.

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive features
- **Git and GitHub** – Version control and source code hosting
- **GitHub Pages** – Website deployment

## Features

- Add, complete, and delete study tasks.
- View task completion progress.
- Use a 25-minute focus timer.
- Pause and reset the timer.
- Responsive layout for different screen sizes.
- Clean and user-friendly interface.

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding tasks and using the focus timer.

No backend server or database is required.

## Deployment Using GitHub Pages

1. Create a public repository named `focusflow-static-website` on GitHub.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open the repository's **Settings** page.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Click **Save** and wait for the deployment to complete.

Your website URL will be:

`https://YOUR-USERNAME.github.io/focusflow-static-website/`

Replace `YOUR-USERNAME` with your GitHub username.

## Limitations

- Study tasks are stored temporarily in browser memory and are not saved permanently.
- The website does not use a backend or database.
- The focus timer works while the webpage is open.
